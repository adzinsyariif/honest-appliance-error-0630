An entry for the make.fun bounty "The Funniest Honest Appliance Error".

`main.py` (Python 3, standard library only, no network) deterministically
writes one line of at most 200 characters — the funniest honest error
message an appliance could show — to `/output/entry.txt`. Both runs write
identical bytes.

The line was chosen by drafting several candidate messages in the
`main.py` docstring, evaluating each against the judge criteria (honest
error, real laugh, plausible fault, flat machine voice, economy), and
adopting the strongest after a tightening revision.
